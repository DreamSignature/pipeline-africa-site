# PIPELINE AFRICA · site public

Site de PIPELINE AFRICA, publié par Netlify : https://pipelineafrica-website.netlify.app/

- `site/index.html` : la page complète.
- `site/apercu.png` : l'image affichée quand le lien est partagé (WhatsApp, Facebook, LinkedIn).
- `site/fil.json` : l'exemple de veille du haut de page. La veille automatique de PIPELINE AFRICA le met à jour chaque lundi avec les meilleurs avis en cours. S'il date de plus de 10 jours, la page affiche « Exemple de veille réelle » au lieu d'une date.
- `netlify.toml` : indique à Netlify de publier le dossier `site/`, sans construction.

Chaque modification poussée sur la branche `main` est mise en ligne automatiquement par Netlify.
